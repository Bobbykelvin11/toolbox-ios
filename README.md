# Toolbox for iOS

All-in-one iOS companion app bringing together 5 open-source tools (iOS 16+):

1. **Stirling-PDF** (`https://stirling.com/app/` or self-hosted URL) — WKWebView with file upload & download (Files / Share Sheet).
2. **OpenCut** (`https://opencut.app/projects` or custom URL) — WKWebView with file upload & download support.
3. **n8n** — User-configurable instance URL with setup guide and links to `n8n.io` and self-hosting docs.
4. **SmartTube** — Info card explaining Android TV-only support with links to SmartTube and the open-source iOS alternative **Yattee**.
5. **Wan2GP** — Info card explaining desktop GPU requirements with link to the repository.

Built as an unsigned IPA (`com.bobbymedia.toolbox`) with XcodeGen and GitHub Actions.
